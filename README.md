# SBB-1
Project SBB untuk proposal 

## Firebase

Konfigurasi Firebase Web berada di `lib/firebase_options.dart` dan digunakan
secara otomatis oleh `lib/main.dart`. Jalankan aplikasi dengan
`flutter run -d chrome`. Proyek Firebase juga harus mengaktifkan metode
**Email/Password** di Authentication jika login email dan password digunakan.
Konfigurasi platform selain Web belum disediakan.
